Architectural Pattern

The Bezos Sandwich Protocol (2026 Edition)

Type-1 decisions (one-way doors) require deep strategic reasoning. Type-2 decisions (two-way doors) are reversible. Never burn frontier reasoning tokens on mechanical compilation or log scrolling.

Stage 1: Frugal Ingestion

Gemini 3.8 Flash

Extracts 0-token AST code skeletons, compresses noisy terminal logs, and constructs a dense <600-token brief.

➔
Stage 2: 1-Shot Frontier Reasoner

Claude Opus 5.5 / o3 / Fable

Frontier reasoning model ingests ONLY the distilled brief. Solves the core algorithmic failure in a single zero-shot decision without thinking token bloat.

➔
Stage 3: Mechanical Execution

Gemini 3.8 Flash / Local AST

Applies exact code diff, runs local pytest verification through the iktisad firewall, and stages clean commit. Total cost: $0.01 instead of $1.50.
